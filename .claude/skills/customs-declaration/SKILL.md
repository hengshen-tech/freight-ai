# 报关单填制与审单规范

本 Skill 只提供**业务规则**。读写 Excel 文件一律按 `xlsx` Skill 的方法做。
公司可以直接编辑本文件，把自己的制单习惯、客户特殊要求沉淀进来。

## 一、工作顺序

1. 先把所有原始单证读完（发票 CI、箱单 PL、合同 SC、订舱/提单、申报要素表等），建立一张「字段 → 值 → 来源」清单，再动模板。
2. 再读模板：逐个 sheet 找出标签单元格和它对应的待填单元格（通常在标签右侧或下方；注意合并单元格只能写左上角）。
3. 复制模板到 `output/` 再填，**绝不修改原模板和原始单证**。
4. 只写待填的空白单元格；模板已有的文字、公式、格式、合并、列宽、打印设置全部保留。
5. 商品行超过模板预留行数时，在明细区内插入行并沿用上一行的格式，不要挤占表尾（合计/签章区）。
6. 填完重新打开输出文件逐格回读核对，并跑一遍下面的校验。

## 二、表头字段取数规则

| 报关单栏位 | 取数来源与规则 |
|---|---|
| 境内发货人 / 收货人 | 出口取合同或发票的卖方（中文全称 + 18 位统一社会信用代码，如有）；进口取买方 |
| 境外收货人 / 发货人 | 发票的 Buyer / Consignee，保留英文原文 |
| 生产销售单位 / 消费使用单位 | 单证未单独说明时与境内发货人相同，并在问题清单里提示人工确认 |
| 合同协议号 | 合同号（Contract / S/C No.），不是发票号 |
| 运输方式 | 海运→水路运输；空运→航空运输；卡车→公路运输；铁路→铁路运输 |
| 运输工具名称及航次号 | 船名/航次，来自订舱确认或提单；没有就留空并提示 |
| 提运单号 | B/L No. 或 AWB No. |
| 监管方式 | 单证未注明时默认「一般贸易(0110)」，并提示人工确认 |
| 征免性质 | 一般贸易对应「一般征税(101)」，并提示人工确认 |
| 贸易国（地区） | 与买方签约方所在国家/地区 |
| 运抵国 / 启运国（地区） | 出口为货物运抵的国家；进口为启运国 |
| 指运港 / 经停港 | 出口填目的港（Port of Discharge） |
| 离境口岸 / 入境口岸 | 装货港对应的口岸 |
| 成交方式 | 取 Incoterms：FOB、CIF、CFR(C&F)、EXW 等，原样填写 |
| 运费 / 保费 | 出口：FOB 不填运保费；CFR 填运费；CIF 运费保费都填。进口相反：FOB 需填运费和保费。单证没有金额时留空并提示 |
| 件数 / 包装种类 | 箱单合计件数；包装种类用海关用语（纸箱、托盘、木箱等） |
| 毛重 / 净重（千克） | 箱单合计，单位统一换算为千克 |
| 标记唛码及备注 | 箱单 Shipping Marks；无唛头填 N/M；集装箱号如有也写在这里 |
| 随附单证 | 单证中出现的许可证、原产地证等编号 |

## 三、商品明细取数规则

- 项号从 1 连续编号；同一 HS 编码、同一品名、同一单价、同一原产国的行可以合并，否则逐行列明。
- 商品编号：10 位 HS 编码。单证给了就用单证的；只有 6 位或 8 位时原样填并提示补足；**没有时不要臆造**，留空并在问题清单给出建议编码供人工确认。
- 商品名称及规格型号：中文品名 + 规格型号 / 申报要素。单证只有英文时给出中文品名，并把英文附在后面。
- 数量及单位：成交数量与单位取发票；法定单位为千克的商品，法定数量取该行净重。
- 单价 / 总价 / 币制：取发票；币制用字母代码（USD、EUR、CNY…）。
- 原产国（地区）：出口一般为中国；最终目的国：一般同运抵国。
- 境内货源地 / 目的地：取生产厂所在地级市，单证没有则留空并提示。
- 征免：一般为「照章征税」。

## 四、必须做的校验（单单一致）

每项都要给出结论，发现不一致写入问题清单：

1. 发票各行 数量 × 单价 = 行金额；各行金额合计 = 发票总金额。
2. 发票与箱单：品名、数量、行数一致。
3. 箱单：件数、毛重、净重各行合计 = 表尾合计；净重 ≤ 毛重。
4. 合同与发票：买卖双方、合同号、币制、成交方式、单价一致；发票金额不超过合同金额。
5. 提单/订舱 与 箱单：件数、毛重、唛头、装货港/目的港一致。
6. 成交方式与运保费逻辑一致（见上表）。
7. HS 编码位数、与品名是否明显矛盾。
8. 模板中所有必填栏位是否都已填；未填的逐项说明原因。

## 五、问题清单的级别

- `error`：会导致退单或申报不实（金额/数量/重量不一致、必填项缺失、HS 明显错误）。
- `warning`：需要人工确认（默认值、推断值、单证间表述不同但可能等价）。
- `info`：已做的换算、合并、默认处理说明。

## 六、底线

- 不编造单证里没有的事实（HS 编码、信用代码、船名航次、金额）。宁可留空并提示。
- 推断或默认得到的值，一律在结果里标 `confidence: "low"` 或 `"medium"` 并写明依据。
- AI 填制结果是草单，最终申报前必须由持证报关人员复核。
